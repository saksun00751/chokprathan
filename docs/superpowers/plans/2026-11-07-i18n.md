# i18n: Thai, English, Lao, Burmese, Khmer (whole site and back office)

Request (2026-11-07): "add 5 languages, th/en/lo/my/km, i18n style, every part, front and back office".

## Decisions

- **Routing:** every page moves under `src/app/[lang]/` (root layout there, `generateStaticParams` = 5 locales,
  so PPR shells are prerendered per language). URLs stay unprefixed: `proxy.ts` rewrites `/x` to `/{locale}/x`
  using the `cp_locale` cookie (then Accept-Language, then `th`). Prefixed URLs (`/en/x`) also work and set the cookie.
  Internal links stay unprefixed. Switching language = set cookie + full reload (clears the client router cache).
- **Locale in code:** Server Components: `getI18n()` via `next/root-params` `lang()`. Server Actions / route handlers:
  cookie `cp_locale` (proxy sets it on every page request). Scheduler/CLI/tests: `th`.
- **Dictionaries:** `src/i18n/locales/<lang>/<namespace>.ts`, Thai is the source of truth; other locales are typed
  `typeof th<Ns>` so TypeScript rejects missing keys. Values are plain strings with `{var}` placeholders (`fmt()`),
  so they serialize to Client Components. Client gets dictionaries through `I18nProvider` (site namespaces in the root
  layout, the admin namespace only in the admin layout).
- **Formatting:** Intl with `-u-nu-latn` (Arabic digits everywhere: lottery numbers and money). Thai keeps the Buddhist
  calendar; other locales use Gregorian. Money stays `฿`.
- **DB content:** banners, promotions, news get an `i18n` JSON column (per-locale overrides, Thai columns are the fallback),
  edited with language tabs in the back office. Site announcement gets per-locale text. Lotto and game names come from
  the dictionary by slug / seed name, falling back to the DB value. Migration 2 adds the columns and backfills the default rows.
- **Fonts:** IBM Plex Sans Thai (th, en) + Noto Sans Lao / Myanmar / Khmer loaded only for that locale; taller line-height
  for my/km.
- **Tests:** a completeness test (same keys, no empty values, same placeholders in every locale) and formatting tests.
- Translations for lo/my/km should be reviewed by a native speaker before launch (say so in the hand-off).
